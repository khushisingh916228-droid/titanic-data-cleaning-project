# Titanic Survival Prediction - Data Cleaning Project

Week 1 mini-project (ML & AI course) — data cleaning, missing value handling, encoding, and visualization on the Titanic dataset.

## Dataset
[Titanic Dataset - Kaggle](https://www.kaggle.com/c/titanic/data)

## Steps
1. Load & explore data (.info(), .describe())
2. Handle missing values (Age → median, Embarked → mode, Cabin → dropped)
3. Encode categorical columns (Sex, Embarked)
4. Visualize age distribution
5. Save cleaned dataset as CSV
